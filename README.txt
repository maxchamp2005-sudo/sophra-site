SOPHRA WEBSITE — QUICK PUBLISHING GUIDE

FILES
- index.html: Home / marketing page
- support.html: Support URL page
- privacy.html: Privacy Policy URL page
- styles.css: Website design

PUBLISH FREE WITH GITHUB PAGES
1. Sign in at github.com and create a new PUBLIC repository named "sophra-site".
2. Upload all four website files from this folder to the repository root.
3. Open the repository's Settings.
4. Select Pages in the left sidebar.
5. Under "Build and deployment," choose "Deploy from a branch."
6. Select branch "main" and folder "/ (root)," then Save.
7. Wait 1–3 minutes. GitHub will display your public site URL.
