# Sophra

Sophra is a personal budgeting app I built to help students and people who are new to budgeting better understand where their money goes and manage it more effectively.

## About the project

I developed Sophra using Flutter and Dart and worked on the project from initial concept through development, testing, debugging, and iOS release.

The app includes:
- Budgeting and spending workflows
- User onboarding
- Persistent user data
- Balance and financial tracking
- UI/UX improvements
- Testing and debugging across devices

## Technologies

Flutter, Dart, Git, iOS, Software Testing, UI/UX

## My role

I designed and developed Sophra independently, including the app logic, interface, testing, debugging, and App Store release process.

## Repository purpose

This repository contains the public website, support page, and privacy policy for Sophra.

The production application source code is maintained privately.

## Related experience

Building Sophra gave me experience taking a software product from an idea to a released application and taught me how to solve technical problems independently throughout the development process.
