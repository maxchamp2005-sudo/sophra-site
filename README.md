# Sophra Website

A polished product-style website for **Sophra**, using the real app screenshots and matching the app's dark / neon-green visual style.

## Included files
- `index.html`
- `styles.css`
- `script.js`
- `support.html`
- `privacy.html`
- `assets/` folder with the screenshots and logo

## How to publish on GitHub Pages
1. Upload all files and the `assets` folder into your `sophra-site` repository.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the `main` branch and `/ (root)`.
5. Save.
